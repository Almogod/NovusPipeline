# NovusPipeline Architecture Blueprint

- **Server Protocol**: Model Context Protocol (MCP) via Stdio transport (`fastmcp` 4.x). Nothing but JSON-RPC may be written to stdout.
- **Runtime**: Python 3.11+.
- **Distribution**: Python package `novuspipeline` (`src/` layout, console script `novuspipeline`), run locally by the user's MCP client. Optional extras: `[gnn]` (torch + PyG), `[llm]` (transformers + peft).
- **Workspace**: the analyzed codebase is `--workspace` / `NOVUS_WORKSPACE_ROOT` (default: working directory). The trained GNN checkpoint ships inside the package (`novuspipeline/models/`); the guideline DB lives in the user data directory (`NOVUS_DATA_DIR`) and seeds itself on first use; per-codebase state (`.novus_index/`, PR drafts, `reports/`) lives in the workspace.
- **Rule Engine**: `modernizer.py`, string/comment-masked regexes plus AST rules for detection; behavior-preserving rewrites only.
- **Ruff Backend**: `ruff_backend.py` runs the bundled Ruff binary (`--isolated`, JSON output) for broad detection (UP, S, B, F, PTH, C4, PIE, SIM, PERF, E9, PLE) and applies only Ruff's *safe* fixes (UP, C4, PIE, SIM). Syntax errors surface as `RUFF-SYNTAX`.
- **Modernization Standards**: `standards.py` loads TOML rule packs (user data dir, then `.novus/standards/`; built-in examples in `standard_packs/` are copied in by `install_standard_pack`). Rules detect calls (import aliases resolved, optional required keyword), imports and masked regexes; fixes rename calls/imports, add keywords or apply regex replacements, each kept only if the result parses. Findings feed the audit, index and risk scores; guidelines are merged into RAG results and the LLM prompt; `validate_proposal` rejects new violations; `enforce = "block"` stops the pipeline. Packs can extend/ignore Ruff codes.
- **Vector DB**: ChromaDB with an offline TF-IDF embedder (`ingest_rag.py`), versioned so stored and query embeddings always match.
- **Structural Code Intelligence**: PyTorch Geometric GraphSAGE (`gnn_model.py`) over AST graphs with type/field/identifier node features (`code_graph.py`), distilled from the rule engine on synthetic + real stdlib code (`train_gnn.py`), stress-tested by `eval_gnn.py`. Exposes pooled graph embeddings for future graph+transformer fusion.
- **Codebase Context**: `codebase_context.py` combines per-function GNN predictions and embeddings with a resolved import graph (dependents, API surface, related tests, structural similarity, hotspots); feeds audits, LLM prompts, test selection and PR descriptions. AST facts come from `code_facts.py` (static, lazy and dynamic imports, `getattr` usage, star imports via `__all__`, definitions, references, rename-insensitive function shapes). Codebase-level smells: import-time cycles (Tarjan SCC), dead code, clones, untested hotspots, god modules, `[deprecated]` APIs from `.novus/config.toml`, unresolvable dynamic imports.
- **History Learner**: `history_learner.py` mines non-merge commits (one `git log --raw`, blobs parsed once) for focused call/import replacements; rules need support across separate commits, consistency, and no adoption of the old call after the last replacement. Incremental state in `.novus_index/learned.json`; runs in a background thread after each index refresh. Only argument-preserving renames with ≥90% consistency are auto-applied, and only through the test-gated pipeline.
- **Sandbox**: `sandbox.py` runs every test command on a temporary project copy (or the pipeline's disposable worktree) with an allowlisted environment and redirected home/temp; Windows Job Objects or POSIX rlimits + process groups for memory/process limits and tree kill; `unshare -rn` network isolation on Linux; optional Docker (`--network none`).
- **Git Integration**: GitPython plus the git CLI (hooks honored); validated branch names; only explicitly modernized files are committed. The autonomous pipeline works in a detached `git worktree`, commits there, moves the target branch with `git branch -f`, and removes the worktree, so the user's working copy and checked-out branch are never touched (CRLF preserved).
- **Verification Engine**: Allowlisted test-runner command shapes only, executed in the sandbox; exit code decides success.
