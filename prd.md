# NovusPipeline PRD (Product Requirements Document)

## Objective
NovusPipeline is an autonomous, RAG-driven legacy codebase modernization engine serving as a Python FastMCP server for Antigravity IDE.

## Core Goals
1. Provide fast, secure, local file reading and modernization guideline querying over Stdio.
2. Execute local tests cleanly in an isolated subprocess environment with tool whitelisting.
3. Automatically stage, commit, and prepare draft PR metadata for modernized code branches.
